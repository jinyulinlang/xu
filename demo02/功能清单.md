# 功能清单与技术说明（前端原型）

## 1. 项目结构（关键文件）

## 2. 功能清单（基于 PRD 的映射）
已实现（原型/可交互）：
- 项目选择：在侧栏展示示例项目，并支持切换（`ProjectList`）。
- 看板（状态泳道）：按状态分列展示任务卡片（`TaskBoard`），支持在下拉中修改状态。
- 进度更新：每个任务支持使用滑块调整完成百分比，进度条实时反映。
- 响应式 UI：针对宽屏与窄屏做了媒体查询，支持 PC 与移动端基本布局。
- 主题风格：深色/科技风配色与卡片样式。

未实现 / 占位（需要后端或更多实现）：
- 任务 CRUD（创建/删除/完整编辑弹窗）——目前仅本地内存示例数据。
- 真实甘特图：仅有占位文字与容器；未实现时间轴绘制与里程碑。
- 通知/预警、用户认证、权限管理（PRD 中的关键 P0 功能需后端支持）。
- 报表导出、API 集成、审计日志、AI 风险预测等高级功能。

映射到 PRD：本原型覆盖 PRD 中的“进度可视化（看板）”、“项目列表/切换”和“进度更新交互”作为演示核心视图。

## 3. 技术架构（前端原型）
- 前端框架：React 18
- 构建工具：Vite
- 组织结构：组件化（Header / ProjectList / TaskBoard）
- 样式：单个全局 CSS（`styles.css`），使用 CSS 变量以便统一主题
- 数据层：当前使用本地静态样例数据（硬编码在组件文件中，使用 React useState 管理）
- 响应式：通过 CSS 媒体查询实现（@media max-width 900px / 480px）
- 可扩展点：建议引入状态管理（如 Redux / Zustand）和接口层（axios/fetch + API 服务封装）用于真实数据交互

组件职责（简述）：
- `App.jsx`：主布局、装载 Header、ProjectList、TaskBoard，持有当前选中项目状态
- `Header.jsx`：展示品牌与简单操作按钮（新建/通知占位）
- `ProjectList.jsx`：列出项目、处理选中
- `TaskBoard.jsx`：渲染多个状态泳道（待开始/进行中/阻塞/已完成），单卡片支持状态下拉与进度滑块

## 4. 部署与运行说明
注意：本项目为前端原型，开发和生产部署方式如下。

先决条件：
- Node.js（建议 v18+）与 npm。你当前环境显示 Node 18.17.1，但 npm 版本较旧（6.x），建议升级 npm 至 8+ 以匹配某些包的 engines 警告，但不影响本地运行。macOS 用户可使用 nvm 管理 Node 版本。

开发（本地热重载）

```bash
cd frontend
npm install
npm run dev -- --host
```

- `npm run dev` 将启动 Vite 开发服务器，默认在 `http://localhost:5173/` 可访问。`--host` 选项可用于在局域网内发布（以便手机或其它设备访问）。

生产构建

```bash
cd frontend
npm install --production=false
npm run build
```

- 构建后静态资源位于 `frontend/dist/`。
- 可通过静态服务器或 CDN 部署，例如：
  - 使用 `vite preview` 预览：

```bash
npm run preview
# 默认在 5173 端口或随机端口上预览构建产物
```

  - 使用 Nginx 部署：将 `dist/` 内容放到 Nginx 对应静态目录，并配置路由回退到 `index.html`（用于 SPA）。

示例 Nginx 配置片段：

```
server {
  listen 80;
  server_name example.com;
  root /var/www/project-task-proto/dist;
  index index.html;

  location / {
    try_files $uri /index.html;
  }
}
```

云托管：
- 可直接部署到 Vercel / Netlify / Cloudflare Pages：将 `frontend` 作为项目导入，构建命令 `npm run build`，发布目录 `dist`。

环境变量与后端 API：
- 如果集成后端，请在构建或运行时注入 API 基础地址，例如 `VITE_API_BASE_URL`。在代码中可通过 `import.meta.env.VITE_API_BASE_URL` 访问。

## 5. 验收测试要点（最小）
- 页面能在 Chrome/Firefox/Safari 中打开，并且侧栏项目可切换（选择变化反映在主区域标题）。
- 在看板中，选择不同状态的下拉框会改变卡片的状态，滑块会改变进度条宽度并显示百分比。
- 在手机宽度（小于 480px）下，布局应自适应，头部文字隐藏以节省空间，侧栏置于顶部。

## 6. 弱点与后续实现建议（技术与产品）
短期（低风险）
- 把样例数据抽成 `src/mock/*.json` 并加入简单接口模拟（使用 `json-server` 或 Vite 的 proxy + 本地 express），便于前后端联调。
- 增加任务详情弹窗（编辑、添加附件、备注历史）。
- 将样式拆分为模块化 CSS 或引入 CSS-in-JS（情境需要）。

中期（核心功能完成）
- 接入真实后端 API：用户认证、项目/任务 CRUD、通知服务。
- 实现甘特图（使用 d3、billboard、frappe-gantt 或 react-gantt 库），并支持里程碑与依赖显示。
- 权限控制、审计日志、导出报表接口。

长期（高级）
- AI 风险建模后端服务（PRD 中定义），以及前端风险可视化组件。
- 企业集成（SSO/LDAP、企业 IM 推送）、多项目组合仪表盘。
