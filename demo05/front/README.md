# Frontend (React + TypeScript)

Install dependencies and run dev server:

```bash
cd front
npm install
npm run dev
```

If the backend runs on a different origin, create a `.env` file with:

```
VITE_API_BASE=http://localhost:8000/api
```

The front implementation uses TypeScript (.tsx). If you don't have Node/npm, install them via Homebrew or nvm.
